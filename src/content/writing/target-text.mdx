## The Problem It Solves

Internal hash links (ToC, footnotes, cross-references) jump the page, but give no visual cue about what changed
Common fix has been JS scroll-listeners + manual class toggling — brittle, extra weight, easy to get wrong

## What ::target-text Actually Does

Styles the exact text fragment a URL's text fragment (#:~:text=) or target anchor resolves to
Browser-native, zero JS required
Works alongside — not instead of — the :target pseudo-class (worth clarifying the distinction here)

## Where It Shines

Navigation — jump to "Key Features" and the exact heading/paragraph lights up
Readability — removes ambiguity about which content a link was "about"
Accessibility — gives keyboard/AT users a clear visual landing point, not just a scroll position
